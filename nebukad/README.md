# Nebukad International — Website preview

Responsive static implementation of the approved Figma direction.

- Cream `#E9E5DB`, black/white NEO TACKLE section, original Nebukad seal.
- Home, Apps, IP portfolio, Contact, legal and privacy placeholder pages; DE/EN.
- No APK downloads or inactive store buttons. No NEO TACKLE website link.
- No promotional contact invitation. Normal navigation/footer contact only.
- All IP entries are placeholders; no registration claims are invented. No register-link column.
- Fonts and logo are served locally. No analytics, embeds, cookies or external font requests introduced.
- `noindex,nofollow` marks the preview for search engines; it is not access control.

## Editing

Run `node build.mjs` after changing text/templates. Styling is in `style.css`; mobile menu behavior in `site.js`.
Run `python -m http.server 8080` in this directory for a local preview.
The generated HTML files are committed so GitHub Pages requires no dependency installation or workflow.

## Before production / store submission

Confirm company address, company register details and business contact email; replace the legal/contact placeholders with complete approved content. Verify the final app behavior and provide individual privacy notices and real support contact information. Add store URLs only after availability is confirmed. Supply IP records, verify founder text, then remove the preview notice and noindex when the production website is approved. These placeholders are not ready for store submission.
